Prototype pollution

OWASP A08 CWE-1321

What it is

In JavaScript, every object copies missing properties from one shared template called the prototype. If an app merges user JSON into an object without checking the keys, an attacker can write into that shared template. From then on, every object in the program inherits the attacker’s values.

The line


      
Highlighted: the merge follows any key the visitor sends, including __proto__, so it writes into the shared template instead of the user’s own settings.

Why it matters

      
One request can change a flag such as isAdmin for every user at once. That can open admin pages, skip permission checks, or crash the app, and in some apps it can lead to running attacker code on the server.

      
Real cases: in 2019 the popular lodash library had this bug in its defaultsDeep function (CVE-2019-10744), and jQuery had it in $.extend (CVE-2019-11358).
